# Tin whistle sounds

## Primary Irish tin-whistle sound

The practice player uses the GeneralUser GS MIDI program 78 “Whistle” preset.
GeneralUser GS identifies this program as an Irish tin whistle and permits the
sound bank to be used and repackaged in software projects. The browser-ready
wavetable conversion is redistributed from the WebAudioFont data repository.

- Sound bank: https://github.com/mrbumpy409/GeneralUser-GS
- GeneralUser GS license: https://github.com/mrbumpy409/GeneralUser-GS/blob/main/documentation/LICENSE.txt
- Browser conversion: https://github.com/surikov/webaudiofontdata/blob/master/sound/0780_GeneralUserGS_sf2_file.js
- WebAudioFont data license: MIT
  https://github.com/surikov/webaudiofontdata/blob/master/LICENSE

The vendored browser preset contains five pitch zones (E4, A4, B4, D5 and A5),
which keeps playback much closer to the recorded pitch than the previous
two-zone fallback. Its SHA-256 hash is:

- `0780_GeneralUserGS_sf2_file.js`: `e60df94eba01026614e68f93cc808e98a612ce94bc9d5efa06fa30b2b3b6c396`
